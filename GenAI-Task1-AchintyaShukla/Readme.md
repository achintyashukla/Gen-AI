# Python Data Structures Assignment 1

This folder contains the solutions for "Assignment 1: Python - Data Structures".

## Files Included

1. `task1.py` - Task 1: Product Collections (Lists & Tuples)
2. `task2.py` - Task 2: Categories (Sets)
3. `task3.py` - Task 3: Product Pricing (Dictionaries)

## How to run

You can run each Python file individually from your terminal or command prompt. Make sure you have Python installed.

```bash
python task1.py
python task2.py
python task3.py
python task4.py
```
