# Assignment 7: Object-Oriented Programming (OOP)

This folder contains the solutions for Assignment 7.

## Folder Structure
- `task1.py` - Basic Class & Object Creation (`Product` class).
- `task2.py` - Constructor & Encapsulation (Private attributes and getters/setters).
- `task3.py` - Inheritance (Single-Level `ElectronicProduct` inheriting from `Product`).
- `task4.py` - Polymorphism (`Laptop` and `Mobile` overriding methods).
- `task5.py` - Abstraction (Abstract base class `Payment`).
- `task6.py` - Magic Methods & Operator Overloading (`__str__` and `__add__`).
- `task7.py` - Mini Project: Simple Inventory System using `Product`, `Inventory`, and `Store` classes.

## How to run
Simply run the `.py` files from your terminal:
```bash
python task7.py
```
