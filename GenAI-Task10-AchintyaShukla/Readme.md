# Tutedude Gen AI Assignment 10: Pandas (Series, DataFrame, Functions, Filtering & Analysis)

This directory contains the solution for Assignment 10, which focuses on data manipulation and analysis using the Pandas library in Python.

## Files

- `assignment10.ipynb`: A Jupyter Notebook containing solutions for all tasks (Task 1 to Task 9) executed in order.

## Execution Instructions

To run the tasks, ensure you have Python, `jupyter`, and the `pandas` library installed.

1. Open your terminal or command prompt.
2. Navigate to this folder (`GenAI-Task10-AchintyaShukla`).
3. Start the Jupyter Notebook server:
```bash
jupyter notebook
```
4. Open `assignment10.ipynb` in your browser and run the cells sequentially.
