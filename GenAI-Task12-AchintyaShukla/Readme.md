# Tutedude Gen AI Assignment 12: Seaborn (Relational, Distribution, Categorical & Multi-Plots)

This directory contains the solution for Assignment 12, which focuses on Exploratory Data Analysis (EDA) and visualization using Seaborn, Pandas, and Matplotlib on the Kaggle Medical Cost Personal Dataset.

## Files

- `assignment12.ipynb`: A Jupyter Notebook containing solutions for all 8 tasks (Relational Plot, Line Plot & Faceting, Distribution Plots, Bivariate Distribution Plots, Matrix Plots, Categorical Plots, Regression Plots, and Multi-Plots / Figure-Level Plots).
- `insurance.csv`: Kaggle Medical Cost Personal Dataset (1,338 records with numerical columns `age`, `bmi`, `children`, `charges` and categorical columns `sex`, `smoker`, `region`).

## Execution Instructions

To run the tasks, ensure you have Python, `jupyter`, `pandas`, `matplotlib`, and `seaborn` installed.

1. Open your terminal or command prompt.
2. Navigate to this folder (`GenAI-Task12-AchintyaShukla`).
3. Start the Jupyter Notebook server:
```bash
jupyter notebook
```
4. Open `assignment12.ipynb` in your browser and run the cells sequentially.
