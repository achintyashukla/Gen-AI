# Assignment 5: Importing, Creating Modules & Packages

This folder contains solutions for Assignment 5.

## Folder Structure
- `math_utils.py` - Contains mathematical functions (`add`, `subtract`, `square`).
- `string_utils.py` - Contains string manipulation functions (`capitalize_words`, `reverse_string`, `word_count`).
- `shop_package/` - A Python package for shop utility functions.
  - `__init__.py` - Initializes the package and exposes the functions.
  - `discount.py` - Contains discount calculation functions.
  - `billing.py` - Contains billing and tax calculation functions.
- `main.py` - The main entry point script that imports and tests all the modules and the package.

## How to run
Simply run the `main.py` file from your terminal:
```bash
python main.py
```
