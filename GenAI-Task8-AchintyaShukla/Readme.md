# Assignment 8: Streamlit (Basic App Building)

This folder contains the solutions for Assignment 8.

## Folder Structure
- `app_basic.py` - Basic Streamlit App with title, text input, button, and dynamic message.
- `app_discount.py` - Price Calculator with number input, slider, calculations, and table display.
- `app_product_form.py` - Product Form using the Streamlit sidebar for inputs and main view for output.
- `app_dashboard.py` - Mini Dashboard with a selectbox, metric display, and a bar chart.

## How to run
Since these are Streamlit apps, you need to run them using the `streamlit run` command from your terminal:

```bash
streamlit run app_basic.py
```
*(You can replace `app_basic.py` with any of the other files to run them instead).*

Make sure you have Streamlit installed in your Python environment:
```bash
pip install streamlit
```
