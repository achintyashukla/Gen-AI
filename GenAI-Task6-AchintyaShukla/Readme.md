# Assignment 6: Exception Handling

This folder contains the solutions for Assignment 6.

## Folder Structure
- `task1.py` - Demonstrates safe division using `try/except/else/finally`.
- `task2.py` - Bill calculator that safely ignores strings and negative numbers in a list using custom/built-in exceptions.
- `task3.py` - Validates age with a custom exception using `raise ValueError`.
- `task4.py` - Safe file reading that handles `FileNotFoundError` and `PermissionError`.
- `task5.py` - Safe Shopping Cart program that takes user inputs iteratively and catches invalid data using exceptions.

## How to run
Simply run the `.py` files from your terminal:
```bash
python task1.py
```
