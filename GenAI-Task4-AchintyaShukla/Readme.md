# Assignment 4: File Handling

This folder contains the solutions for "Assignment 4: File Handling (Read, Write, Append, Modes)".

## Files Included

- `Assignment4.ipynb`: A single Jupyter Notebook containing all 7 tasks for this assignment. 

## How to run

Since the code is contained within a Jupyter Notebook, you can open it in an IDE that supports notebooks (like VS Code or JupyterLab). Alternatively, you can view it directly on GitHub.

*Note: Some tasks that require user input (`input()`) have been hardcoded with sample values to prevent the notebook from hanging when executed entirely. You can uncomment the `input()` lines in the code cells to test them interactively.*
