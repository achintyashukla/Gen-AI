# Tutedude Gen AI Assignments

This repository contains solutions for the Tutedude Gen AI Assignments.

## Repository Structure

- **[GenAI-Task1-AchintyaShukla/](./GenAI-Task1-AchintyaShukla/)**
  - **Topic**: Python Data Structures
  - **Description**: Covers the use of lists, tuples, sets, and dictionaries to manage product collections, categories, and pricing.

- **[GenAI-Task2-AchintyaShukla/](./GenAI-Task2-AchintyaShukla/)**
  - **Topic**: Python Control Flow (Conditionals & Loops)
  - **Description**: Focuses on `if/elif/else` statements, `for` loops, and `while` loops to apply discount rules, process multiple orders, and create user menus.

- **[GenAI-Task3-AchintyaShukla/](./GenAI-Task3-AchintyaShukla/)**
  - **Topic**: Python Functions
  - **Description**: Introduces user-defined functions, recursive functions, lambda functions, and higher-order functions like `map()` and `filter()` for data manipulation and GST calculations.

- **[GenAI-Task4-AchintyaShukla/](./GenAI-Task4-AchintyaShukla/)**
  - **Topic**: File Handling (Read, Write, Append, Modes)
  - **Description**: Focuses on reading from and writing to files safely using context managers, extracting insights from text files, and appending data without deleting original content.
