# Tutedude Gen AI Assignment 11: Matplotlib (Core Plot Types & Visualization)

This directory contains the solution for Assignment 11, which focuses on creating core data visualizations directly with `matplotlib.pyplot` using the Kaggle Sample Superstore Sales dataset.

## Files

- `assignment11.ipynb`: A Jupyter Notebook containing solutions for all 7 tasks (Line Plot, Scatter Plot, Bar Plot Vertical & Horizontal, Multiple Bar Plot, Stacked Bar Chart, Histogram, and Pie Chart).
- `superstore.csv`: Sample Superstore sales dataset (9,994 order records) used across the visualization tasks.

## Execution Instructions

To run the tasks, ensure you have Python, `jupyter`, and `matplotlib` installed.

1. Open your terminal or command prompt.
2. Navigate to this folder (`GenAI-Task11-AchintyaShukla`).
3. Start the Jupyter Notebook server:
```bash
jupyter notebook
```
4. Open `assignment11.ipynb` in your browser and run the cells sequentially.
