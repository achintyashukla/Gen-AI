# Python Control Flow Assignment 2

This folder contains the solutions for "Assignment 2: Python - Control Flow (Conditionals & Loops)".

## Files Included

1. `task1.py` - Task 1: Discount Rules (if / elif / else)
2. `task2.py` - Task 2: Process Multiple Orders (for loop)
3. `task3.py` - Task 3: User Menu (while loop + break/continue)
4. `task5.py` - Task 5: Loop Control with Conditions (break & continue) (Named according to the numbering in the assignment prompt)

## How to run

You can run each Python file individually from your terminal or command prompt. Make sure you have Python installed.

```bash
python task1.py
python task2.py
python task3.py
python task5.py
```
